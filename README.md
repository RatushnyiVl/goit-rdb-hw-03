# Homework 3 — Bank Marketing Dataset (PostgreSQL + SQLAlchemy)

## Джерело даних

**UCI Machine Learning Repository — Bank Marketing Dataset**
https://archive.ics.uci.edu/dataset/222/bank+marketing

Датасет містить результати телемаркетингових кампаній португальського банку,
спрямованих на продаж строкового депозиту. Кожен рядок описує один контакт
із клієнтом: демографічні ознаки, параметри поточного дзвінка та результат
попередньої кампанії. Цільова змінна `y` вказує, чи підписав клієнт депозит.

Використана повна версія датасету (`bank-full.csv`), 17 колонок.

## Структура репозиторію

```
.
├── content/
│   ├── hw3_dataset.csv        # сирий CSV-файл датасету (UCI Bank Marketing)
│   └── sql_comnds/
│       ├── com1.sql           # SQL-команда(и) створення staging-таблиці
│       └── com2.sql           # SQL-команда(и) створення типізованої (clean) таблиці
├── temp/                      # локальна PostgreSQL база (pgserver), створюється автоматично
└── hw_t3_template.ipynb       # основний notebook — точка запуску всього pipeline
```

- **content/** — робоча директорія з даними; CSV завантажується автоматично
  всередині notebook, якщо відсутній локально.
- **sql_comnds/** — об'ємні SQL-команди (`CREATE TABLE`, обмеження CHECK, тощо)
  винесені в окремі `.sql`-файли для читабельності notebook; виконуються
  з коду через `text()` / `exec_driver_sql()`.
- **temp/** — каталог даних локального PostgreSQL-сервера (`pixeltable_pgserver`),
  створюється й ініціалізується автоматично при першому запуску notebook.
- **hw_t3_template.ipynb** — головний файл: підіймає локальну БД, завантажує CSV,
  створює staging- та clean-таблиці, виконує EDA-запити.

## Інструкція запуску

### Вимоги
- Python 3.9+
- Jupyter Notebook / JupyterLab
- Пакети: `pixeltable-pgserver`, `sqlalchemy`, `pandas`, `psycopg2-binary`

Встановлення залежностей:

```bash
pip install pixeltable-pgserver sqlalchemy pandas psycopg2-binary
```

### Кроки

1. Клонувати репозиторій та перейти в його кореневу директорію.
2. Відкрити `hw_t3_template.ipynb` у Jupyter.
3. Виконати комірки послідовно зверху вниз:
   - **Підняття локальної БД** — notebook стартує локальний PostgreSQL-сервер
     через `pixeltable_pgserver`, дані сервера зберігаються в `temp/`.
   - **Завантаження датасету** — якщо `content/hw3_dataset.csv` відсутній,
     notebook завантажує його з UCI-репозиторію автоматично.
   - **Створення staging-таблиці** — сирі дані завантажуються в таблицю
     без типізації через `COPY FROM STDIN` (SQL — у `sql_comnds/com1.sql`).
   - **Створення clean-таблиці** — типізована таблиця з `CHECK`-обмеженнями
     та приведенням типів (SQL — у `sql_comnds/com2.sql`).
   - **EDA-запити** — серія SQL-запитів для дослідження даних та бізнес-питань.
4. Результати запитів повертаються як `pandas.DataFrame` через кастомну функцію
   `sql_reader(запит:str)`.

### Примітка щодо повторного запуску

Оскільки `temp/` містить стан локальної БД, повторний запуск notebook
перевикористовує вже підняту базу. Для чистого старту достатньо видалити
вміст `temp/` перед запуском.
